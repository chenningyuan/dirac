
Generic files
-------------

All the files in the directory cmake (not in its subdirectories)
are generic and should not contain any program-specific information.
They are shared between several codes:

ConfigCompilerFlags.cmake
ConfigGitRevision.cmake
ConfigSafeGuards.cmake
ConfigureScript.cmake
FindBLAS.cmake
FindGit.cmake
FindLAPACK.cmake
FindSphinx.cmake
Math.cmake
MathLibFunctions.cmake
SaveCompilerFlags.cmake

Also the following subdirectories are generic:

binary-info
parallel-environment


Code-specific files
-------------------

Are found in:

architecture
compilers
packaging
testing


Generated files
---------------

The files in subdirectory pamadm-generated
are generated by pamadm and should normally
not be edited by hand.

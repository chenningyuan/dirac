XCFun

XCFun is a library of approximate exchange-correlation functionals, used in the Density Function Theory description of electronic structure. Because XCFun is based on automatic differentiation, the library provides arbitrary order derivatives of all supported functionals, needing only an implementation of the exchange-correlation energy expression. For this reason the library is very well suited for high order time dependent DFT or for the development of new functionals.

Supported functionals

All functionals are implemented for general spin-polarization, using either α and β or α+β and α-&beta quantities as the basic variables. Currently the following functionals are supported:
  • Slater (LSDA) Exchange
  • VWN5 (LSDA) Correlation
  • Becke Exchange
  • LYP Correlation
  • PW91 Exchange
  • PW92 Correlation
  • (rev)PBE Exchange
  • PBE Correlation
The following functionals are being implemented and tested:
  • Thomas-Fermi (LDA) Kinetic energy
  • PW91k Kinetic Energy
  • M06 family of functionals
  • srLDA short-range exchange and correlation

Implementation

The library is implemented in C++, but does not rely on the C++ standard library. It can be used from Fortran programs through a provided F90 module interface.

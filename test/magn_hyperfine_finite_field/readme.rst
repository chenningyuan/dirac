Cl(2P3/2) atom 
==============

Magnetic hyperfine operator as finite-field perturbation in CCSD(T).

X 2P3/2 state of Cl, with the occupation 1s(2) 2s(2) 2p(6) 3s(2) 3p12(2) 3p32(3)

ccpVDZ decontracted basis set; C2 symmetry for the A_x operator

using orbital energies in RelCC to get CC convergence

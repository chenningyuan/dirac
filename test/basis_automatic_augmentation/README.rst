Basis sets augmentation
=======================

The purpose is to test nonstandard automatic augmentation of standard basis sets, like
cc-pVXZ, Turbmole and dyall.

In the following table we demonstrate influence of basis set extension on the total 
(nonrelativistic) energy and on the dipole moment, calculated as simple SCF wave-function expectation value.

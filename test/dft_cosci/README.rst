=========
DFT-COSCI
=========

Test suite of the DFT-COSCI (or DFT-RESOLVE) feature.

Single determinant open-shell DFT with fractional occupation is followed by
the Kramers unrestricted COSCI, which determines the multiplets within open-shell active space.

By default, the transformed matrix elements for COSCI step contain the DFT exchange-correlation term.

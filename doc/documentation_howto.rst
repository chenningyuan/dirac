

How this documentation works and how you can contribute
=======================================================

This documentation is generated using sphinx http://sphinx.pocoo.org/
which translates RST (ReStructured Text) markup to html and latex.

The nice thing about RST markup that it looks nice by itself
in the terminal.

RST is very simple and intuitive and for first steps use these guides:
* http://docutils.sourceforge.net/docs/user/rst/quickstart.html
* http://docutils.sourceforge.net/docs/user/rst/quickref.html
* http://docutils.sourceforge.net/docs/user/rst/cheatsheet.txt

Typically RST markups is auto-colored in the terminal so you can
see when the markup is correct or wrong.

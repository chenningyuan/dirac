Suggestion box
==============

From Diracwiki
~~~~~~~~~~~~~~

Jump to: `navigation <#column-one>`_, `search <#searchInput>`_

Here we can collect mental notes, ideas, and suggestions for the wiki
content/setup/layout/functionality:

-  We will need a nice logo for the top-left part (not now, but on the
   Amsterdam server eventually). Do we want to keep P. A. M. Dirac's
   photo or design something new?

-  In the "navigation" box (left) we can probably remove (eventually):
   "Random page" and "Donations".

-  There are many "undocumented features" that are a barrier for new
   DIRAC programmers, like the symmetry scheme, the symmetry packing of
   matrices, ..., we could think about documenting them somewhere in the
   wiki.

-  We could add a ready-to-copy-paste bibtex entry for DIRAC.

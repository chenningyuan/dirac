Clarify
=======

From Diracwiki
~~~~~~~~~~~~~~

Jump to: `navigation <#column-one>`_, `search <#searchInput>`_

Some statements in the manual can be difficult for outsider to
understand. In order to improve the manual you can insert {{clarifyme}}
into the text. Sections marked with this keyword can then be found on
`this
page <http://wiki.chem.vu.nl/dirac/index.php/Category:Articles_needing_clarification>`_,
and fixed by an expert.

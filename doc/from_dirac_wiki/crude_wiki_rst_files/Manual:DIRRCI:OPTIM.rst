&OPTIM -- Fine tuning of the algorithm
======================================

`|image0| </dirac/index.php/Image:HJAaJ.png>`_

**Programmers options**

IGENEX
------

Write coupling coefficients to file (default):

::

    IGENEX=2

Calculate coupling coefficients when needed:

::

    IGENEX=1

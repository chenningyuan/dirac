Licensing and download
======================

We will distribute the code freely to all academic users.

An academic user in this context defined to be anyone doing research
destined for publication in the open literature, and not doing
proprietary research.

We will require all users to sign a `personal license
agreement <http://dirac.chem.sdu.dk/obtain/Dirac-license.shtml>`_ or a
`site license
agreement <http://dirac.chem.sdu.dk/obtain/Dirac-site_license.shtml>`_.

For site licenses, we require that the site keeps the source code
confidential and does not modify it or release it to users at the site.

We require that all work published which is based on use of the DIRAC
program cite it by the `appropriate
reference </dirac/index.php/Citation>`_. We will also require that when
certain features of the code have been used, the papers describing the
implementation is to be cited, as indicated in the output from the
program.

The authors of the program accept no responsibility for the performance
of the code, nor the correctness of the results obtained. No support is
given, but a mailing list exists.

You will be emailed a download link for the program once the appropriate
license has been emailed or faxed to

    Remember to attach a scanned copy of the signed licence form.

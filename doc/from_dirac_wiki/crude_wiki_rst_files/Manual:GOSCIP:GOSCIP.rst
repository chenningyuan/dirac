&GOSCIP -- Specify the CI space
===============================

NELEC
-----

Number of electrons (excluding frozen core electrons).

*Default:*

::

    NELEC=0

**NOTE: in the developer's version this line reads as**

NELACT
------

Number of electrons (excluding frozen core electrons).

*Default:*

::

    NELACT=0

`|image0| </dirac/index.php/Image:HJAaJ.png>`_

**Programmers options**

IPRNT
-----

Print level.

*Default:*

::

    IPRNT=0

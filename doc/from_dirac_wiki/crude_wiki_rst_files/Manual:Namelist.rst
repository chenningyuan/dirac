Manual:Namelist
===============

From Diracwiki
~~~~~~~~~~~~~~

Jump to: `navigation <#column-one>`_, `search <#searchInput>`_

Some parts of DIRAC reads input in the Fortran *namelist* format. These
statements are put *after* the ``*END OF INPUT`` statement in the DIRAC
input file.\ :sup:`[*please `clarify </dirac/index.php/Clarify>`_*]`\

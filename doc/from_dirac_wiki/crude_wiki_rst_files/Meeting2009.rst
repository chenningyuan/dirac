Dirac meeting Odense Aug 24 - 26 2009
=====================================

Prologue
--------

Sunday 23/8
~~~~~~~~~~~

evening: Mongolian BBQ

Schedule
--------

Please add speakers and sessions to the schedule.

Monday 24/8
~~~~~~~~~~~

The state of affairs
^^^^^^^^^^^^^^^^^^^^

-  9:00 -- 10:45 Node leaders

   -  9.00 -- 9.20 Opening. Hans Jørgen Jensen
   -  9.20 -- 9.30 Overview of projects in Odense. Hans Jørgen Jensen
   -  9.30 -- 9.40 Overview of projects in Strasbourg. Trond Saue
   -  9.40 -- 9.50 Overview of projects in Amsterdam. Luuk Visscher
   -  9.50 -- 10.00 Overview of projects in Linköping. Patrick Norman
   -  10.00 -- 10.10 Overview of projects in Tromsø. Kenneth Ruud
   -  10.10 -- 10.20 Overview of projects in Toulouse / Düsseldorf. Timo
      Fleig
   -  10.20 -- 10.30 Overview of projects in Tel Aviv. Ephraim Eliav
   -  10.30 -- 10.45 Summary and mapping out of overlapping efforts. All

-  10:45 -- 11:00 Break

DFT developments
^^^^^^^^^^^^^^^^

-  11:00 --12:30 DFT developers

   -  11:00 -- 11:30 Present status of the DFT module in DIRAC and
      outlook. Radovan Bast
   -  11:30 -- 12:00 Automatic differentiation in Dirac. Ulf Ekström
   -  12:00 -- 12:30 Free slot or discussion time

-  12:30 -- 13:30 Lunch

Licensing, website & wiki
^^^^^^^^^^^^^^^^^^^^^^^^^

-  

   -  13:30 -- 13:50
   -  13:50 -- 14.30 Licensing for DIRAC09 and generic modules (LGPL ?).
      *Discussion session*
   -  14:30 -- 15.00 Technical set-up of the Dirac homepage and wiki
      (let's decide on a solution and implement it). Ulf Ekström.
   -  15:00 -- 15.15 Summary and to-do list. All

-  15:15 -- 15:30 Break

Work to be done
^^^^^^^^^^^^^^^

-  15:30 -- 17:30 Work on to-do list.

Tuesday 25/8
~~~~~~~~~~~~

High performance computing
^^^^^^^^^^^^^^^^^^^^^^^^^^

-  9.00 -- 9.25 Dirac and `CUDA <http://en.wikipedia.org/wiki/CUDA>`_ -
   useful compute acceleration for (large-scale) applications? *Stefan
   Knecht. (Sorry, I am not in Odense, maybe next year if you are
   interested?)*

   -  9.25 -- 9.50 MPI macro functions/subroutines for more readable and
      safer parallel codes. Stefan Knecht and Radovan Bast.
   -  9.50 -- 10.15 Memory management. Andre Gomes
      `Presentation <http://wiki.chem.vu.nl/dirac/images/d/d3/Diracmeeting09_memory.pdf>`_.
   -  10.10 -- 10.40 Free slot. ???

-  10:40 -- 11:00 Break

User Interfaces and Interoperability
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

-  

   -  11:00 -- 11:20 Priority list for usability (suggestions welcome).
   -  11:20 -- 12:00 Input and interface file formats.
   -  12:00 -- 12:30 Error handling.

-  12:30 -- 13:30 Lunch

New applications with Dirac
^^^^^^^^^^^^^^^^^^^^^^^^^^^

-  

   -  13:13 -- 14.00 Core excitations with Dirac. Paul Bagus.

-  15:15 -- 15:30 Break

Work to be done
^^^^^^^^^^^^^^^

-  

   -  15:30 -- 17:30 Work on to-do list.

   -  10.10 -- 10.40 Free slot. ???

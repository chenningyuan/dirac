The Dirac mailing list
======================

Any question or comment related to use of the Dirac program package can
be sent to the Dirac mailing list,

dirac-usersVEDdirac.chem.sdu.dk

provided you are a subscriber to the list (in order to avoid spam mail -
you can subscribe using the link below). Someone (either an author or a
user) might give you an answer to your question.

NB! If you use any of the e-mail addresses on this page: In your e-mail
program you MUST change the three letters "VED" to "@" in the "To:"
field.

How to subscribe
----------------

Everybody can subscribe to the Dirac mailing list. Just send a mail to

dirac-users-requestVEDdirac.chem.sdu.dk

with Subject:subscribe. All new licence holders will automatically be
added to the list.

How to unsubscribe
------------------

To be removed from the Dirac mailing list again, just send a mail to

dirac-users-requestVEDdirac.chem.sdu.dk

with Subject:unsubscribe.

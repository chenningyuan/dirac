.SAOP The more general version of .SAOP! - followed by a single line of
input.

*typical input (here correcting LDA):*

::

    **HAMILTONIAN
    .DFT
    LDA
    *DFT
    .SAOP
    LBalpha

Single line following .SAOP : asymptotic potential (currently LB94 or
LBalpha).

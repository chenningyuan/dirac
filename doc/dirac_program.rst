Dirac Program
=============

Program for Atomic and Molecular Direct Iterative Relativistic All-electron Calculations
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The DIRAC program computes molecular properties using relativistic
quantum chemical methods.

It is named after `P.A.M.
Dirac <http://en.wikipedia.org/wiki/Paul_Dirac>`_, the father of
relativistic electronic structure theory.
